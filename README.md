# ResearchTool (Fabric, client-side)

Учебный клиентский мод для локального исследования клиент-серверного взаимодействия.

## Важно
- Проект реализован как **безопасный исследовательский инструмент** без выдачи административных прав.
- Не включает намеренную фальсификацию привилегированных действий сервера.
- Любые диагностические сообщения/панели работают локально.

## Что реализовано
- Панель `/fa` и клавиша `R`.
- Вкладки: игроки, локальный мир, эксперимент движения, исследование телепортации, настройки.
- Блокировка `CreativeInventoryActionC2SPacket` с локальным предупреждением.
- Локальная консоль `/faconsole` (Swing).
- Имитация `/give` через `/fagive <item>` (локальное сообщение).
- Логирование движения: `logs/researchtool-movement.log`.

## Сборка
```bash
./gradlew build
```
